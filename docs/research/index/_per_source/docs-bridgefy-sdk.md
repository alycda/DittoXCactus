## Elevator summary

Bridgefy SDK is a production mesh-networking and on-device AI platform for mobile apps, enabling offline-first communication and content distribution over Bluetooth and Wi-Fi Direct. Relevant to Mesh RAG as a mature alternative mesh layer and a case study in commercializing offline-first features; architecture and UX patterns are worth studying.
