## Reading the table

- **R@3**: number of expected-topic notes that appear in the top 3 / max possible.
- **MRR**: reciprocal rank of the *first* matching note in the full ranking.
- **Case**: does the top-1 note change when the query is lowercase vs. title-case? `stable` is good; anything else means the model's embedding head is case-sensitive in a way that affects retrieval. The on-device pipeline title-cases queries to compensate (see `retrieval_service.dart`).
